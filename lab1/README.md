# ER-модель даних ШІ мобів (RTS / squad / individual)

## Домен

Доменом обрано структуру mob squads (команд мобів) для гри в жанрі RTS (Real-Time Strategy). Моби можуть бути в команді, виконує завдання від SquadAI. Гравець або ШІ відповідної фракції можуть створювати команди та визначати для них цілі атаки.

## Вимоги

- Команду та завдання можуть створювати гравці та ШІ
- Моб належить лише до однієї команди
- Команда транслює ціль(і) у завдання для мобів (є також функціональною вимогою)
- Моб може виконувати лише одне завдання одночасно
