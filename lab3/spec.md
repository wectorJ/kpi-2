# UC-04 — Розформувати Squad

**Актор:** Player. **Мета:** видалити власний Squad і звільнити його Mob. Player надсилає команду через ігровий інтерфейс. Сервіс керування Squad знаходить загін за ID і перевіряє власника. Якщо загін належить Player, сервіс знімає з кожного Mob призначення Task і членство у Squad, зберігає власника Mob та видаляє загін. Інтерфейс оновлює список після отримання `SUCCESS`.
