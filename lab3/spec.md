# UC-04 — Розформувати Squad

**Актор:** Player. **Мета:** видалити власний Squad і звільнити його Mob. Player надсилає команду через ігровий інтерфейс. Сервіс керування Squad знаходить загін за ID і перевіряє власника. Якщо загін належить Player, сервіс знімає з кожного Mob призначення Task і членство у Squad, зберігає власника Mob та видаляє загін. Інтерфейс оновлює список після отримання `SUCCESS`.

## Учасники

- **Player** ініціює розформування й отримує результат.
- **Ігровий інтерфейс** передає команду сервісу, оновлює список загонів або показує помилку.
- **Сервіс керування Squad** перевіряє існування та власника загону і застосовує зміни.
- **Squad, Mob і Task** — сутності [ER-моделі lab1](../lab1/erd.mmd). Діаграма показує зняття призначення Task через Mob.

## Сценарії

UC-04 із [карти варіантів використання lab2](../lab2/use_cases.md#uc-04--розформувати-squad) доповнено сценаріями SC-10–SC-13. Їхні передумови, дії та результати записані в [gherkin_uc04.md](gherkin_uc04.md).

| Сценарій | Перебіг і результат | Діаграма |
| --- | --- | --- |
| SC-10 — розформування Squad з Mob | Сервіс звільняє Mob і знімає призначення Task, видаляє Squad та повертає `SUCCESS`. Інтерфейс оновлює список. | [uc04.mmd](uc04.mmd) |
| SC-11 — видалення порожнього Squad | Сервіс пропускає звільнення складу, видаляє Squad та повертає `SUCCESS`. Інтерфейс оновлює список. | [uc04.mmd](uc04.mmd) |
| SC-12 — спроба розформувати неіснуючий Squad | Сервіс повертає `SQUAD_NOT_FOUND`. Інтерфейс показує помилку без оновлення списку. | [uc04.mmd](uc04.mmd) |
| SC-13 — спроба розформувати Squad опонента | Сервіс знаходить Squad, виявляє іншого власника й повертає `ACCESS_DENIED`. Інтерфейс показує помилку, а Squad, його склад і призначення Task зберігаються. | [sc-13.mmd](sc-13.mmd) |
