# Actors
- Operator - сутність, що керує належними йому Squad, Targets. Існує у вигляді Player або AIOpponent
- Player - фізичний гравець, може бути лише один у грі. Під керуванням має Squad, Mobs, Targets. Без гравця дії у системі не відбуваються
- AIOpponent - штучний інтелект, може бути кілька **(не риба)** у грі
- System - ігровий рушій, керує окремими Mobs, якщо ті не під безпосереднім контролем Operator. Має прямий доступ до виконання Tasks Мобом.
