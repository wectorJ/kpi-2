# language: en

Feature: Створення команди

  Background:
    Given існують вільні моби відповідної фракції

  Scenario: Гравець створює команду з вільних мобів
    Given гравець керує відповідною фракцією
    When гравець створює команду та обирає вільних мобів своєї фракції
    Then система створює команду під керуванням гравця
    And обрані моби стають членами цієї команди

  Scenario: Гравець обирає моба, який уже входить до команди
    Given моб відповідної фракції вже входить до іншої команди
    When гравець обирає цього моба для нової команди
    Then система показує попередження, що моб уже входить до команди
    And система запитує підтвердження вибору

  Scenario: Гравець підтверджує вибір моба з іншої команди
    Given система попередила гравця, що обраний моб уже входить до іншої команди
    When гравець підтверджує вибір моба для нової команди
    Then моб стає членом нової команди
    And моб більше не входить до попередньої команди

  Scenario: Опонент ШІ створює команду
    Given існує опонент ШІ відповідної фракції
    When опонент ШІ створює команду та обирає мобів своєї фракції
    Then система створює команду під керуванням цього опонента ШІ
    And до команди потрапляють лише обрані вільні моби

Feature: Призначення та пріоритизація цілей команди

  Background:
    Given існує команда мобів відповідної фракції
    And існують доступні цілі цієї фракції

  Scenario: Гравець призначає команді цілі у визначеному порядку
    Given команда підпорядковується гравцеві
    When гравець призначає команді цілі у визначеному порядку
    Then система створює для команди Tasks відповідно до порядку цілей
    And моби команди отримують упорядкований список Tasks
    And кожен моб виконує перший Task у своєму списку

  Scenario: Опонент ШІ призначає команді цілі у визначеному порядку
    Given команда підпорядковується опоненту ШІ
    When опонент ШІ призначає команді цілі у визначеному порядку
    Then система створює для команди Tasks відповідно до порядку цілей
    And моби команди отримують упорядкований список Tasks
    And кожен моб виконує перший Task у своєму списку

  Scenario: Гравець змінює активну ціль команди
    Given команда підпорядковується гравцеві
    And моб команди виконує Task для поточної активної цілі
    When гравець змінює активну ціль команди
    Then система змінює Task моба відповідно до нової активної цілі
    And моб виконує Task для нової активної цілі

Feature: Зміна складу команди гравцем

  Background:
    Given існує команда, що підпорядковується гравцеві

  Scenario: Гравець видаляє моба з команди
    Given моб входить до команди гравця
    When гравець видаляє моба з команди
    Then моб більше не входить до цієї команди
    And моб стає вільним

  Scenario: Гравець додає вільного моба до команди
    Given існує вільний моб фракції гравця
    When гравець додає моба до своєї команди
    Then моб стає членом цієї команди

  Scenario: Гравець розформовує команду
    Given команда гравця містить мобів
    When гравець розформовує команду
    Then команда перестає існувати
    And моби цієї команди стають вільними

Feature: Безпосереднє керування мобом гравцем

  Scenario: Гравець керує вільним мобом
    Given існує вільний моб фракції гравця
    When гравець бере моба під безпосереднє керування та віддає йому команди
    Then система передає команди гравця цьому мобу
    And система не виконує щодо цього моба дій, крім передавання команд гравця

  Scenario: Гравець перехоплює моба зі своєї команди
    Given моб входить до команди гравця та виконує Task
    When гравець бере моба під безпосереднє керування
    Then виконання Task цього моба зупиняється
    And моб тимчасово вважається вільним і підпорядкованим гравцеві
    And безпосереднє керування триває до завершення дій гравця або смерті моба

Feature: Трансляція цілей у список завдань

  Scenario: Система перетворює ціль команди на Tasks для мобів
    Given існує команда з мобами та щонайменше однією призначеною ціллю
    When система отримує ціль команди
    Then система перетворює ціль на впорядкований список Tasks
    And система передає список Tasks мобам команди
    And кожен моб виконує не більше одного активного Task
    And інші Tasks моба залишаються в черзі
    And система контролює виконання мобами їхніх Tasks
